## Grounds for the distinction

1. **Preservation does not imply publication.** A record may be important evidence while remaining unsuitable for unrestricted distribution.
2. **Reflection does not become governing Orientation through placement.** Publishing a situated reflection beside Orientation sources may invite mistaken attribution of authority.
3. **Source-local standing remains intact.** Incomplete reception is not a failed receipt to be rewritten; a later reflection does not supersede an earlier one.
4. **Internal operating details need separate scrutiny.** Exact pins, version access, memory carriers, routing, and candidate architecture can be discussed methodologically without publishing all operational particulars.
5. **Attribution matters.** Joint dialogue, first-person agent accounts, and Architect corrections must not be recast as a single voice or universal rule.
6. **A public GitHub branch is public.** An unmerged branch is not confidential storage; do not upload non-public source bodies merely because they are placed under `research/`.
